# 評価仕様書兼報告書アプリ

評価（テスト）仕様書の作成・実施記録・エビデンス管理・納品用報告書の出力を、**ブラウザだけ**で行う静的 Web アプリです。
サーバー不要・ビルド不要で、GitHub Pages にそのまま置いて使えます。

- データとエビデンス画像はブラウザ内（IndexedDB）に保存されます。外部に送信されることはありません。
- PC・スマホの両方に対応しています（スマホでは一覧がカード表示になり、カメラで撮影したエビデンスも追加できます）。
- 初回起動時にサンプルプロジェクト（8項目・画像付き）が自動作成されます。

## 画面と機能

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | 判定ごとの件数、進捗バー、OK率、エビデンス未添付件数、「OKなのにエビデンスなし」一覧、NG一覧、大項目別・担当別の集計 |
| 一覧 | 表形式（判定バッジ・エビデンスのサムネイル）。大項目・判定・担当・キーワード・要確認のみで絞り込み。判定バッジをクリックすると判定をその場で変更 |
| 詳細パネル | 行クリックで開く。全項目の編集（自動保存）、判定のワンクリック切替、エビデンスの追加（**Ctrl+V 貼り付け／ドラッグ＆ドロップ／ファイル選択／スマホは撮影**）、並べ替え・削除、クリックで拡大表示 |

**項目（標準構成）**：ID / 大項目 / 小項目 / 前提条件 / 手順 / 期待結果 / 実績 / 判定（OK・NG・保留・未実施）/ 担当 / 実施日 / エビデンス（複数画像）/ 備考

### 便利機能

- 判定を OK・NG・保留にすると、実施日が空なら**今日の日付を自動入力**
- 「OKなのにエビデンスなし」を一覧・詳細・ダッシュボード・報告書で警告表示
- 詳細パネルのショートカット：`1`〜`4` で判定（OK/NG/保留/未実施）、`j`/`k` または `Alt+↓`/`Alt+↑` で次/前の項目、`Esc` で閉じる

## 使い方

### 1. 仕様書を用意する
- 新規：メニュー →「新規プロジェクト」→ 一覧で「＋ 項目を追加」
- 既存の Excel から：メニュー →「Excel 仕様書を取り込み」
  - シート・見出し行は自動推定されます（変更可）。
  - 列の対応付け画面で、各項目に対応する列を選びます（「期待値」「操作手順」「結果」などの表記ゆれは自動で推定）。
  - 結合セル・空欄の大項目／小項目は上の行を引き継げます。判定の「○ × △」等は OK/NG/保留 に変換されます。
  - 「現在のプロジェクトに追加」「置き換え」「新しいプロジェクトとして作成」から選べます。

### 2. 実施・記録する
一覧で行をクリック → 詳細パネルで判定をクリック → 実績を記入 → 画面キャプチャを **Ctrl+V** で貼り付け。

### 3. チームで受け渡す
- メニュー →「プロジェクトを保存（.zip）」：JSON＋画像を1つの ZIP に保存します。
- 受け取った側はメニュー →「プロジェクトを読み込み（.zip）」。同じプロジェクトが既にある場合は「上書き」か「別プロジェクトとして読み込む」を選べます。
- ブラウザのデータ削除で消えることがあるため、**定期的に ZIP 保存してバックアップ**してください。

### 4. 納品用に出力する

| 出力 | 内容 |
| --- | --- |
| PDF 報告書 | 表紙（承認印欄つき）→ サマリ → 一覧 → 各項目詳細（エビデンス画像付き）。プレビュー画面の「印刷 / PDF保存」から、印刷先に「PDF に保存」を選びます。用紙 A4 縦、「背景のグラフィック」ON 推奨。日本語はブラウザのフォントで出力されるため崩れません。 |
| 閲覧専用 HTML | 画像を埋め込んだ単体 HTML。オフラインで開け、絞り込み・行クリックで詳細表示・画像の拡大が可能。編集はできません。 |
| Excel＋エビデンス ZIP | `報告書.xlsx`（サマリ／評価一覧シート）と `evidence/<ID>/` フォルダ。一覧の「エビデンス1〜」列から画像へ**相対リンク**しています。ZIP を展開してから開いてください。 |

## GitHub Pages の設定手順

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source** で「**Deploy from a branch**」を選ぶ
3. **Branch** で `main`、フォルダは `/ (root)` を選び **Save**
4. 数分後、ページ上部に表示される URL（例：`https://<ユーザー名>.github.io/test-report/`）を開く

※ プライベートリポジトリで Pages を使うには、GitHub の有料プラン（Pro / Team / Enterprise）が必要です。

## 補足・注意事項

- **データの保存先**：ブラウザ（およびプロフィール）ごと・URL（オリジン）ごとに別々です。別の PC や別のブラウザとは ZIP で受け渡してください。シークレットウィンドウではウィンドウを閉じると消えます。
- **ライブラリ**：Excel 処理に [SheetJS](https://sheetjs.com/)、ZIP 処理に [JSZip](https://stuk.github.io/jszip/) を CDN から必要時に読み込みます。これらの機能だけはインターネット接続が必要です（編集・PDF 出力はオフラインでも動作）。
- **ローカルで動かす場合**：`index.html` を直接開いても動きますが、ブラウザによっては `file://` で IndexedDB が制限されるため、`python3 -m http.server` などで配信して `http://localhost:8000/` を開くのが確実です。
- 対応ブラウザ：最新の Chrome / Edge / Safari / Firefox。
