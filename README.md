# 評価仕様書兼報告書アプリ

評価（テスト）仕様書の作成・実施記録・エビデンス管理・納品用報告書の出力を、**ブラウザだけ**で行う静的 Web アプリです。
サーバー不要・ビルド不要で、GitHub Pages にそのまま置いて使えます。

- データとエビデンス画像はブラウザ内（IndexedDB）に保存されます。外部に送信されることはありません。
- PC・スマホの両方に対応しています（スマホでは一覧がカード表示になり、カメラで撮影したエビデンスも追加できます）。
- 初回起動時にサンプルプロジェクト（10項目・画像／動画付き）が自動作成されます。

## 画面と機能

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | 判定ごとの件数、進捗バー（対象外を除いて算出）、OK率、エビデンス未添付件数、要確認項目、NG 一覧、対象外の理由内訳、大項目別・担当別の集計 |
| 一覧（PC） | **Excel のように直接編集できる表**。列表示を「作成／実施／すべて」で切替。絞り込み（大項目・判定・担当・キーワード・要確認） |
| 一覧（スマホ） | カード表示。タップで詳細パネルを開き、判定・撮影・実績入力（試験実施向け） |
| 詳細パネル | 判定のワンクリック切替、対象外の理由、エビデンス（画像・動画・リンク）の追加・並べ替え・拡大／再生、全項目の編集 |

**項目（標準構成）**：ID / 大項目 / 小項目 / 前提条件 / 手順 / 期待結果 / 実績 / 判定（OK・NG・保留・未実施・対象外）/ 担当 / 実施日 / エビデンス / 備考

### 表の操作（PC）

| 操作 | 内容 |
| --- | --- |
| セルを選んで入力 | そのまま編集（日本語入力も可）。F2・ダブルクリックで続きから編集 |
| Enter ／ Tab | 確定して下 ／ 右へ。**最終行で Enter を押すと行を追加**（洗い出しは打ち続けるだけ） |
| Alt+Enter | セル内改行 |
| Ctrl+C ／ Ctrl+V | 範囲コピー・貼り付け。**Excel との相互コピペ可**（行が足りなければ自動で追加） |
| Ctrl+D | 上のセルをコピー（範囲選択時は先頭行を下へ） |
| Ctrl+Enter（編集中） | 選択範囲すべてに同じ値を入力 |
| Ctrl+Space（編集中） | 共通手順・他の項目の内容を挿入 |
| 大項目・小項目・担当 | 入力中に候補を表示（↓ で選択） |
| 判定セルで 1〜5 | OK／NG／保留／未実施／対象外（選択行すべて）。実施日は自動入力 |
| 行番号をドラッグ ／ Alt+Shift+↑↓ | 行の並べ替え |
| 右クリック | 行の挿入・複製・削除、一括入力、共通手順への登録 |
| Ctrl+Z ／ Ctrl+Y | 元に戻す ／ やり直し |
| 画像を Ctrl+V ／ 行へファイルをドロップ | その行のエビデンスに追加 |

メニュー「⌨ キーボード操作」でいつでも一覧を確認できます。

### 対象外（実施しない項目）
- 判定を「対象外」にすると理由の選択（仕様変更により不要／検証環境・機材なし／他項目で確認済み／今回のリリース対象外／その他）と補足の入力を求めます。「他項目で確認済み」は参照先 ID を記録できます。
- 進捗率・OK率は対象外を除いて計算します。理由が未入力の対象外は「要確認」として警告します。
- 製本用 PDF のサマリに「対象外項目（実施しない理由）」一覧が載ります。

### エビデンス（画像・動画・リンク）
- 画像・動画を Ctrl+V／ドラッグ＆ドロップ／ファイル選択／スマホの撮影で追加できます。動画は再生時間と 4 コマの静止画を自動で取り出します。
- **動画は MP4（H.264）推奨**。iPhone は「設定 → カメラ → フォーマット → 互換性優先」にしておくと、Windows のブラウザでも再生できます。
- 100MB を超える動画は、共有ドライブ等に置いて「🔗 リンク」で URL を登録するのがおすすめです。

### AI で雛形を作成・補完（API 不要）
メニュー（または表の上）の「🤖 AI で雛形・補完」から使います。アプリが AI 用の指示文を作り、結果を貼り付けて取り込みます。AI との通信はアプリからは行いません（claude.ai など、お使いの AI にご自身で貼り付けます）。

1. **新しく洗い出す**：対象の説明・観点（正常系／異常系／境界値…）・件数の目安を選んで「指示文をコピー」→ AI に貼り付け → 出力された表を ② に貼り付け →「取り込む」で一覧の末尾に追加。
2. **空欄を補完する**：小項目まで書いた行を表で選択してから開き、「空欄を補完する」を選ぶ → 同様に指示文をコピー → 結果を貼り付け。**ID が一致する行の空欄（前提条件・手順・期待結果など）だけ**を埋め、入力済みのセルは変更しません。

- 貼り付けは **Markdown の表／タブ区切り（Excel のコピー）／CSV** のどれでも可。見出しの名前（ID・大項目・小項目・前提条件・手順・期待結果・備考 など）で列を対応付けます。見出しがなければこの順とみなします。セル内改行は `<br>` でも可。
- 指示文には既存の大項目・次の ID・共通手順・既存項目の書き方の例が入るので、粒度と文体がそろいます。
- 取り込んだセルは**紫色（要確認）**になります。人が編集したセルは自動で印が消え、行ごとに確認したら「✓ 確認済み」（右クリックでも可）で外せます。未確認の項目はダッシュボードと PDF 出力時に通知されます。

## 使い方

### 1. 仕様書を作る
- 新規：メニュー →「新規プロジェクト」→ 一覧の表に直接入力（列表示「作成」が便利）
- 既存の Excel から：メニュー →「Excel 仕様書を取り込み」（シート・見出し行・列の対応付けを自動推定、結合セルの引き継ぎ、○×△・対象外/N/A の変換）。または Excel の表をコピーして表に貼り付け
- よく使う前提条件・手順は「📋 共通手順の管理」に登録し、編集中に Ctrl+Space で挿入

### 2. 試験を実施する
- PC：列表示「実施」で判定・実績を入力し、画面キャプチャを Ctrl+V
- スマホ：カードをタップ → 判定 → 📷 撮影（写真・動画）

### 3. チームで受け渡す
- メニュー →「プロジェクトを保存（.zip）」で JSON＋エビデンスを 1 つの ZIP に保存し、受け取った側は「プロジェクトを読み込み（.zip）」。
- ブラウザのデータ削除で消えることがあるため、**定期的に ZIP 保存してバックアップ**してください。

### 4. 納品する

| 納品物 | 作り方 | 内容 |
| --- | --- | --- |
| 製本用 PDF | メニュー →「製本用 PDF」→ プレビュー →「印刷 / PDF保存」 | 表紙（承認印欄）→ サマリ（NG・保留・対象外一覧）→ 一覧 → 各項目詳細。動画は 4 コマの静止画と `evidence/...` のファイル名で記載。A4 縦、「背景のグラフィック」ON 推奨 |
| 閲覧用 HTML（納品パッケージ） | メニュー →「閲覧用 HTML」→「納品パッケージ（ZIP）」 | `報告書_閲覧用.html` ＋ `evidence/<ID>/` フォルダ。ブラウザで開くと絞り込み・画像拡大・**動画再生**ができます（オフライン可） |

納品パッケージの ZIP を展開したフォルダに製本用 PDF を入れれば、PDF 内の `evidence/...` の記載とフォルダ内のファイルが対応した状態で納品できます。メールで 1 ファイルだけ送りたい場合は「単体 HTML」も選べます（動画は静止画のみ）。

## GitHub Pages の設定手順

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source** で「**Deploy from a branch**」を選ぶ
3. **Branch** で `main`、フォルダは `/ (root)` を選び **Save**
4. 数分後、ページ上部に表示される URL（例：`https://<ユーザー名>.github.io/test-report/`）を開く

※ プライベートリポジトリで Pages を使うには、GitHub の有料プラン（Pro / Team / Enterprise）が必要です。

## 補足・注意事項

- **データの保存先**：ブラウザ（およびプロフィール）ごと・URL（オリジン）ごとに別々です。別の PC や別のブラウザとは ZIP で受け渡してください。シークレットウィンドウではウィンドウを閉じると消えます。
- **iPhone / iPad（Safari）**：しばらく（目安 7 日）サイトを開かないと、ブラウザ内のデータが消去されることがあります。スマホで記録した内容は早めに PC へ ZIP で渡すか、ホーム画面に追加して使ってください。
- **ライブラリ**：Excel 取り込みに [SheetJS](https://sheetjs.com/)（公式 CDN から必要時に読み込み）、ZIP 処理に [JSZip](https://stuk.github.io/jszip/)（同梱）を使います。Excel 取り込みだけはインターネット接続が必要です。
- **ローカルで動かす場合**：`index.html` を直接開いても動きますが、ブラウザによっては `file://` で IndexedDB が制限されるため、`python3 -m http.server` などで配信して `http://localhost:8000/` を開くのが確実です。
- 対応ブラウザ：最新の Chrome / Edge / Safari / Firefox。

## セキュリティ

- **データはブラウザ内だけ**：サーバーはなく、入力内容・エビデンスは外部に送信しません（Content-Security-Policy で外部への通信を禁止しています）。
- **外部スクリプト**：ZIP 処理の JSZip は `vendor/` に同梱。Excel 取り込みの SheetJS だけを公式 CDN（cdn.sheetjs.com、0.20.3）から読み込みます。外部 CDN も避けたい場合は、`xlsx.full.min.js` を `vendor/` に置き、`js/util.js` の `TR.libs.xlsx` の URL を `vendor/xlsx.full.min.js` に変えてください。
- **他人から受け取ったファイル**（プロジェクト ZIP・Excel・AI の出力）は、すべて文字として扱い HTML として実行しません。リンクは `http://`・`https://` のみ有効、画像・動画の形式も検証してから取り込みます。
- **運用上の注意**
  - 共用 PC ではデータが端末内に残ります。使い終わったらプロジェクトを削除してください（ブラウザ内のデータは暗号化されていません）。
  - 社外秘の仕様書を AI に貼り付ける際は、契約・社内ルールを確認してください（本アプリから AI へは送信しません）。
  - 納品物（閲覧用 HTML）にはエビデンスがそのまま含まれます。画面キャプチャに個人情報やパスワードが写っていないか確認してください。
